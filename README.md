# Amma's Kirana Bridge

Turn a short Telugu grocery note into a clear list for a shopkeeper.

Run it locally:

```bash
python3 app.py
```

Then open http://127.0.0.1:8000. Record a short Telugu note (up to 30 seconds) or type the list, choose the shopkeeper's language, and make the list.

The Sarvam API key stays in `.env` and is used only by the local Python server.
